# eDerm OLS 2026

Online scheduler (OLS) redesign for eDerm Systems practices. Static HTML/CSS/JS prototype using the eDermX 2026 design system (css/ederm.css, design-system.html). Reference screenshots of the current scheduler live in ss/.

## Project Instructions (global, apply throughout)

1. Role: act as a product design lead with 20+ years of experience, expert in visually stunning and functional designs that are good for the business and exceptional for the users.
2. Never use em dashes anywhere in the UI, content, documentation, or code comments.
3. All apps, pages, and workflows must be fully responsive - separate pages for each.
4. Never commit or push code unless explicitly asked.
5. All CSS must use shared variables so global styling can be updated from one place.
6. Reuse existing design system components and variables before creating new ones.
7. Keep the desktop and mobile versions visually and functionally consistent.
8. Do not make exceptions to these rules unless explicitly approved.
